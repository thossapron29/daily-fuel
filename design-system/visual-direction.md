# Daily Fuel visual direction

The active palette is **Blue & Butter**, following the user's muted-blue and butter-yellow direction. ui-ux-pro-max informs hierarchy, accessibility and responsive behavior; the user's requested palette overrides generic generated color recommendations.

## Active palette

| Role | Color | Use |
| --- | --- | --- |
| Canvas | #EDF3F6 | A soft blue tint across the entire app |
| Dusty blue | #48677E | Logo, links, icons and interaction states |
| Soft blue | #D9E6EE | Welcome illustration, selected profile and weight card |
| Butter | #F1DFA1 | Primary actions |
| Butter cream | #F7EDC7 | Shared recipe card and supporting notes |
| Paper | #FFFEF9 | Nutrition cards, journals, forms and dialogs |
| Ink | #2E4758 | Headings and key nutrition values |
| Muted ink | #4E6475 | Supporting text with readable contrast on tinted cards |

The SVG illustrations use blue clothing, a butter apron and coordinated ceramics. Skin, tomatoes and vegetables keep natural colors. Avatars follow the same blue/yellow palette.

## Alternative for review

**Butter Morning** uses a butter-cream canvas and warm welcome card, keeping blue for the energy visualization and accents. It feels warmer and closer to a cafe. This is a preview only; Blue & Butter remains the implemented default.

## Shared rules

- Manrope and Noto Sans Thai; bold, rounded headings with quieter labels.
- Hierarchy: daily energy, macros, meal journal. BMR and TDEE are supporting information.
- Original editable SVG illustrations.
- No fabricated nutrition, meals or progress.
- Macro plan cards show Moderate Carb (P/C/F 30/35/35), Lower Carb (40/20/40) and Higher Carb (30/50/20), all based on the selected calorie goal. The saved plan feeds the Dashboard. These are selectable presets, not a claim of a universally optimal diet.
- Responsive grids, native date picker, accessible dialogs, visible keyboard focus and reduced motion.
- Theme changes apply to navigation, profiles, all pages, forms, dialogs and sign-in.
